# Vinícius Souza Fotografia — Mockups Frontend

Preview navegável de mockups HTML/CSS para revisão por amigos e colegas.

## Telas disponíveis

- **[Site público](./publico.html)** — galeria de eventos, carrinho, checkout, área pública
- **[Painel cliente](./cliente.html)** — área autenticada do cliente: compras, favoritos, downloads
- **[Painel admin](./admin.html)** — gestão do fotógrafo: eventos, fotos, vídeos, pedidos, configurações

Ou abra `index.html` para a página inicial de navegação.

## Tech

HTML estático + CSS tokens + JS mínimo. Sem build, sem dependências. Renderiza direto no browser.

## Status

Mockups em iteração — feedback bem-vindo. Reportar bugs/sugestões via issues ou direto pro Vinícius.
